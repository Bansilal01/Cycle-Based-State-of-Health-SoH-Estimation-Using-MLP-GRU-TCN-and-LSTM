# Cycle-Based-State-of-Health-SoH-Estimation-Using-MLP-GRU-TCN-and-LSTM
Cycle-based battery State of Health (SoH) estimation using MLP, GRU, TCN, and LSTM deep learning models. Includes data processing, training, and evaluation scripts for benchmarking model performance on cycle-indexed battery datasets.

This repository contains datasets and related resources for analyzing Li-ion battery performance and aging. The datasets included here, specifically B0005, B0006, and B0007, are sourced from the NASA Li-ion Battery Aging Datasets provided by the NASA Prognostics Center of Excellence (PCoE).

**Dataset Description**
The datasets (B0005, B0006, B0007) contain experimental data on Li-ion battery charge, discharge, and electrochemical impedance spectroscopy under various operating conditions. These datasets are widely used for research in battery health monitoring, prognostics, and predictive maintenance.

**Source**
The datasets can be downloaded from the NASA Open Data Portal. They are provided under the Creative Commons Zero (CC0) license, allowing unrestricted use, modification, and distribution, provided proper attribution is given.

**Dataset Details**
B0005: Data from a Li-ion battery cycled under specific charge/discharge conditions.
B0006: Data from a Li-ion battery with different operating profiles.
B0007: Data from a Li-ion battery subjected to similar aging tests.
For detailed descriptions of the experimental setup, data format, and test conditions, refer to the dataset documentation on the NASA Open Data Portal.
